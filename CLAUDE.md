## Vigie code graph

This project is indexed by Vigie (symbols, call graph, blast radius). Use the MCP tool
`vigie_explore` for architecture questions — "how does X work", "how does X reach Y",
surveying an area. One call returns the relevant symbols' source, callers/callees and
impact radius. Prefer it over grep/glob/Read for exploration, and answer directly instead
of delegating exploration to sub-agents.
